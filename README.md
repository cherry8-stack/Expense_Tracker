💰 Expense Tracker

 Project Overview

This project started as a simple Python practice project and gradually evolved into a functional expense management application. The goal was to move beyond writing small programs and learn how individual Python concepts can come together to build something practical.

The application allows users to record, view, manage, and track their expenses through a simple graphical interface.

✨ What It Can Do

- Add new expenses with details such as category, amount, and description
-  View recorded expenses
-  Delete individual expenses
-  Calculate total spending
-  Save expense data using JSON
-  Provide an easy-to-use graphical interface

 Technologies Used

-  Python
-  Tkinter
-  JSON
-  Git & GitHub

🧠 What I Learned

Building this project helped me understand how Python concepts work together in a real application.

Along the way, I worked with functions, lists, dictionaries, loops, user input, file handling, JSON data, GUI development, and Git/GitHub.

More importantly, I learned that building an application is not just about making the code run. Handling data properly, organizing the program, fixing errors, and improving the user experience are all part of the process.


🌱 Project Journey

What began as a beginner Python project is becoming a small application that I can continuously improve as I learn more about software development.

The main objective is not just to finish the project, but to keep building on it and understand why each part of the application works.
